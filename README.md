# Py Game Vault

A personal stash of retro arcade mini-games built in Python.

I started this project to mess around with Python basics—mainly game loops, coordinate systems, and basic collision handling without relying on bulky game engines. 

Right now, it has a working Snake game, but I'll be adding more retro mini-games here over time (like Tetris, Pong, Breakout, etc.).

---

### Games Included

#### 1. Snake (`snake.py`)
The classic Nokia-style snake game. Eat the food dots, grow your snake, and don't slam into the walls or your own tail.

- **Controls:** Arrow keys
- **Goal:** Eat as much as you can and rack up a high score.

### 2. Tetris (`tetris.py`)
The classic falling-block puzzle game. Rotate and place falling tetrominoes to clear complete horizontal lines and keep the board from filling up.
- **Controls:** 
  - Left / Right Arrow: Move piece
  - Up Arrow: Rotate piece
  - Down Arrow: Soft drop
- **Goal:** Clear lines, rack up points, and survive as long as possible.

*(More mini-games on the way)*
